# S&P 500 vs. VIX Market Analysis

## Project Overview

This project uses Python to collect, process, and visualize historical S&P 500 and CBOE Volatility Index (VIX) data to explore the relationship between stock market performance and market volatility.

The goal is to demonstrate how financial data can be collected programmatically and used to investigate trends and relationships in financial markets.

## Tools & Technologies

- **Python** – Data collection and analysis
- **Pandas** – Data cleaning and manipulation
- **Matplotlib** – Data visualization
- **Web Scraping** – Retrieving historical financial market data

## Project Objectives

1. Collect historical S&P 500 and VIX data using Python.
2. Clean and organize the datasets for analysis.
3. Visualize historical trends in market performance and volatility.
4. Explore how changes in market volatility relate to S&P 500 movements.

## Methodology

The project involves retrieving historical financial data, preparing the datasets using Pandas, and creating visualizations to examine market behavior over time.
